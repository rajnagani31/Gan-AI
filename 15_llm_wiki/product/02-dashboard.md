# Dashboard Page

The Dashboard is the first page shown after a user signs in. It provides a quick view of current work.

## Dashboard widgets

- Active Projects: number of projects that are currently open.
- Open Tasks: tasks that are not complete.
- New Submissions: recent responses from published forms.
- Recent Activity: latest changes made in the workspace.

Use the date filter in the upper-right corner to select a reporting period. Selecting a widget opens the related page. Owners and admins can select **Edit dashboard** to add, remove, or reorder widgets.
