# Projects Page

Projects organize work for a specific team, customer, or goal. To create a project, open **Projects**, select **New project**, complete the required fields, and select **Create**.

## Project details

Set a project name, owner, start date, due date, status, and description. Each project contains Overview, Tasks, Files, and Activity tabs.

## Managing projects

Project owners and admins can change project status, assign tasks, upload files, archive a project, or delete it. Archived projects remain searchable but cannot be edited. Deleting a project permanently removes its tasks and files.
