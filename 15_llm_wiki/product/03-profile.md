# Profile Page

Open the avatar menu in the top-right corner and choose **Profile** to manage personal account details. Profile updates apply only to the signed-in user.

## Personal details

Users can update their display name, job title, profile photo, and preferred time zone. Select **Save changes** to apply updates.

## Notifications

The Notifications section controls email and in-app alerts. Users can choose to receive alerts for task assignments, mentions, form submissions, and project updates.

## Password and security

Open **Profile > Security > Change password**. Enter the current password, enter the new password twice, then select **Update password**. The new password must contain at least eight characters, including a number and a symbol.

Users can also enable two-factor authentication in Security. After enabling it, a verification code is required during sign-in.
